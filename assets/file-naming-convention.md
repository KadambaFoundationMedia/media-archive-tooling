# Media file naming convention

## For optimal search and sorting any media file

1. # YYYY-MM-DD\_

Each filename **must** start with: **YYYY-MM-DD\_**  
This is an [ISO date standard](https://en.wikipedia.org/wiki/ISO_8601) 

### Missing dates?

Missing day: Use YEAR-MONTH. Example: 2018-09-DD\_  
Missing Month: Use YEAR\_MM. Example: 2018-MM-01\_  
No date: Use YYYY-MM-DD\_

2. # The 3 WWW

Each filename must provide the **WHO, WHAT and WHERE.**

Example 1: 2013-11-14\_KKS\_SB-9-20-20-27\_Vrindavan\_in.mp4  
Example 2: 2023-01-16\_KKS\_CC-Raghunatha-das-goswami\_Amsterdam\_nl.mp3

| Who | Who speaks | KKS |
| :---- | :---- | :---- |
| **W**hat \* | What is it | SB-9-20-27CC-Raghunatha-das-goswamiSB-8-1-30\_Balancing-our-livesDo not use dots\! |
| **W**here  | Location, country | Vrindavan\_in Amsterdam\_nl |

**NOTE** → All related media files, the video, audio, texts, transcript, etc, must have the exact same file name structure according to the official file naming convention.

# File naming best practices

* File names should be short but descriptive (\<25 characters, max 128\) (Briney, 2015\)  
* Use only 1 dot in the filename  
* Use lowercase for the file name extension (mp3, not MP3, or txt and not TXT)  
* Avoid special characters or spaces in a file name  
  * Allowed: \_ \- (underscore, hyphen)  
  * **Not allowed: \!@\#$%^&\*()+=\[\]{}\\|:;”‘\<\>?/**
